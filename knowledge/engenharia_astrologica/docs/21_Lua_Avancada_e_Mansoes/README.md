# 21 Lua Avançada e Mansões Lunares

A Lua é o intermediário entre o eterno e o temporal — a matriz da encarnação.

---

## Lua Pré-Natal (Syzygy)

- Lua Nova pré-natal e Lua Cheia pré-natal
- Lunação anterior ao nascimento (Prenatal Syzygy)
- Fase lunar natal (posição Sol-Lua no mapa)
- Lua como matriz de encarnação
- Eclipse pré-natal e sua influência
- Condição lunar antes do nascimento

*(Tradição: Helenística, Medieval, Esotérica)*

## Lua Fora de Curso (Void of Course)
- Definição e cálculo
- O que evitar
- O que favorece
- Lua fora de curso em trânsito
- Lua fora de curso no mapa natal

## Fases Lunares
- Lua Nova → Crescente → 1º Quarto → Gibosa Crescente
- Lua Cheia → Gibosa Minguante → Último Quarto → Balsâmica
- Significado de cada fase
- Fase natal como temperamento da alma

## Mansões Lunares Árabes (Manazil al-Qamar)

*(Não confundir com o sistema indiano. Esta é a tradição árabe-ocidental medieval.)*

- 28 Mansões Lunares
- Estrelas associadas a cada mansão
- Natureza de cada mansão (benéfica/maléfica)
- Eleições lunares por mansão

### Aplicações
- Magia lunar por mansão
- Medicina lunar
- Agricultura lunar
- Talismãs lunares
- Mansões para viagens
- Mansões para amor
- Mansões para proteção
- Mansões para riqueza

### Fontes
- Astrologia Árabe Medieval
- Picatrix
- Cornelius Agrippa (*De Occulta Philosophia*)
- Magia renascentista
