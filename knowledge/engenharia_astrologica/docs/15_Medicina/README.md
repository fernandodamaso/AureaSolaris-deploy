# 15 Astrologia e Medicina

A correlação simbólica entre os astros e o corpo humano.

Este bloco é documental: ele preserva o que diferentes linhagens ocidentais efetivamente ensinaram sobre corpo, humores, melotésia, crise, prognóstico e terapêutica astrológica. Quando houver uso contemporâneo, ele deve aparecer como camada separada, não como correção do texto histórico.

## Tópicos
- Temperamentos, Humores, Partes do corpo
- Planetas e funções vitais
- Astrologia Médica Ocidental (Iatroastrologia, Melotesia, Doenças crônicas, Crises médicas)
