# 07 Estrelas Fixas

As estrelas de primeira magnitude e sua simbologia astrológica.

> [!NOTE] **Entradas YAML instanciadas** (com `porque_simbolico:` + linha tradicional): `Regulus`, `Aldebaran`, `Antares`, `Sirius`, `Spica`. (Algol, Fomalhaut, Vega, Arcturus, Pollux — stubs prontos para expandir.)

## Fundamento
- Ptolomeu (Tetrabiblos) → base helenística
- Tradição árabe (Albategnius, Al-Biruni)
- Renascentista (Agrippa, Culpeper)
- Moderna: correspondência com planetas (ex.: Regulus ≈ Júpiter + Marte)

## Como Usar
- Conjunção natal (estrela no mapa) = marca de fundo
- Ativação por trânsito (passagem da estrela por planeta/ângulo) = janela de evento
- Natureza da estrela (benéfica/maléfica/mista) = tom do evento
