> 💎 **Como usar esses 4:** eles alimentam a **camada de sentido** (por que, como guiar) — não a **técnica de julgamento** (que vem de Valens/Bonatti/astro.com/Skyscript). Misturar gera contradição silenciosa (Manual, Regra 8). Ao citar, marcar a escola.

### Observação sobre fontes nacionais (BR)
Não há portal web BR com nível "Fonte Base" para estudo técnico sério. O material BR de peso vive em **livros** (ex.: autores como Carlos Hollanda, Maria Helena Vargas — via editoras/PDF). Para consulta diária, priorize astro.com + Skyscript; o BR serve para cálculo rápido (Personare) e inspiração de conteúdo (redes).

## Como usar estas fontes

1. Abrir o caminho/link correspondente.
2. Buscar o trecho relevante.
3. Usar como fonte da anotação — com referência explícita (autor, obra, escola).
4. Registrar na seção `✏️ Minhas Anotações` do arquivo correspondente (ou instanciar no YAML).
5. Conteúdo web transitório → cite e armazene o trecho-chave; não confie que o link ficará vivo.
