## Camada Energética (o coração)
Cada planeta é uma *frequência* que impressiona a mente → emoção → acontecimento **provável** (astrologia inclina, não determina). Ao ler um planeta no mapa, pergunte: que correnteza mental ele está gerando no consulente? (Ver `00_Filosofia`, seção IV.)
