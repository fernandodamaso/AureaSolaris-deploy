# 🔤 B — Linguagem Astrológica

Antes da técnica, existe a linguagem. Os símbolos astrológicos são o alfabeto; as regras são a gramática; a interpretação é a poesia.

---

## Tópicos
- Planetas como verbos (o que fazem)
- Signos como adjetivos (como fazem)
- Casas como substantivos (onde fazem)
- Aspectos como conjunções (a relação entre)

---

## Os Planetas
- Sol, Lua, Mercúrio, Vênus, Marte (pessoais)
- Júpiter, Saturno (sociais)
- Urano, Netuno, Plutão (transpessoais)
- Quíron, Ceres, Juno, Vesta, Pallas, Eris (asteroides)

---

## Os Signos
- Polaridades (Ativo/Receptivo)
- Elementos (Fogo, Terra, Ar, Água)
- Modalidades (Cardinal, Fixo, Mutável)
- Decanatos, Termos, Faces

---

## As Casas
- Angulares (1, 4, 7, 10) — manifestação
- Sucedentes (2, 5, 8, 11) — sustentação
- Cadentes (3, 6, 9, 12) — transição

---

## Os Aspectos
- Ptolomaicos e menores
- Orbe, Aplicação, Separação

---

## Dignidades
- Domicílio, Exaltação, Triplicidade, Termos, Faces
- Queda, Exílio, Peregrino

---

## Outros Elementos
- Estrelas Fixas
- Partes Arábicas (Lotes)
- Antiscia e Contra-antiscion
- Graus especiais
