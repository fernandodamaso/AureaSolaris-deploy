# 🌿 Qualidades Físicas dos Signos

Cada signo tem:
- **Cor** tradicional
- **Parte do corpo** regida
- **Elemento físico** (Fogo, Terra, Ar, Água)

> As Qualidades Físicas dos **Planetas** estão em `08_Qualidades_Fisicas/`.
> As Qualidades Físicas dos **Signos** estão aqui.

| Signo | Cor | Parte do Corpo |
|-------|-----|----------------|
| Áries | Vermelho | Cabeça, face |
| Touro | Verde, rosa | Pescoço, garganta |
| Gêmeos | Amarelo | Braços, mãos, pulmões |
| Câncer | Prata, branco | Estômago, mamas |
| Leão | Dourado, laranja | Coração, dorso |
| Virgem | Verde-terra, marrom | Intestinos, sistema digestivo |
| Libra | Azul-claro, rosa | Rins, lombar |
| Escorpião | Vermelho-escuro, preto | Órgãos genitais |
| Sagitário | Azul-escuro, roxo | Coxas, quadris, fígado |
| Capricórnio | Marrom, preto | Ossos, joelhos, pele |
| Aquário | Azul-elétrico, violeta | Tornozelos, sistema nervoso |
| Peixes | Violeta, verde-água | Pés, sistema linfático |
