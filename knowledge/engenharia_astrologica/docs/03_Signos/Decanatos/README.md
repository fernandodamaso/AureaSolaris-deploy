# 🗂 Decanatos (Decans)

Cada signo zodiacal divide-se em **3 decanatos de 10°**:

- **Decanato 1** (0°–10°) = signo puro
- **Decanato 2** (10°–20°) = signo matizado pelo signo seguinte do mesmo elemento
- **Decanato 3** (20°–30°) = signo amadurecido pelo signo anterior do mesmo elemento

> Exemplo: Áries Fogo
> - Dec 1 = Áries puro (Marte)
> - Dec 2 = Áries + Leão (Sol)
> - Dec 3 = Áries + Sagitário (Júpiter)

## Regentes de triplicidade

| Elemento | Tradicional | Moderna |
|----------|-------------|---------|
| Fogo | Sol/Sol/Sol | Marte / Sol / Júpiter |
| Terra | Vênus / Mercúrio / Saturno | Vênus / Mercúrio / Saturno |
| Ar | Mercúrio / Vênus / Saturno | Mercúrio / Vênus / Urano |
| Água | Lua / Marte / Júpiter | Lua / Plutão / Netuno |

> ⚠️ **Divergências registradas:** Saturno→Urano (Ar), Marte→Plutão (Água), Júpiter→Netuno (Água). Sempre cite a escola usada.

## Como usar

Abra o arquivo do decanato desejado. Cada YAML tem:
- Regente moderno + tradicional
- `camada_energetica:` (pensamento, emoção, manifestação)
- `origens_e_divergencias:` (escola + divergência)
