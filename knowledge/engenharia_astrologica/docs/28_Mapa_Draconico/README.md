# 🐉 28 — Mapa Dracônico (Eixo do Dragão)

> **O Mapa Dracônico não é um mapa separado.** É uma **leitura específica do mapa natal** focada no eixo Nodo Norte/Nodo Sul (Cabeça e Cauda do Dragão).

## O que é

- **Nodo Norte (Cabeça do Dragão)** = o que a alma veio **DESENVOLVER** nesta vida
- **Nodo Sul (Cauda do Dragão)** = o que a alma já **DOMINA** de vidas passadas
- O dragão "come" a Lua nos eclipses = pontos de poder cármico

## Como usar

1. Abra o mapa natal
2. Encontre o Nodo Norte e o Nodo Sul (signo + casa)
3. Leia o signo = **qualidade** da energia
4. Leia a casa = **área da vida** onde atua
5. Verifique aspectos = lições específicas

## Estrutura

| Elemento | Significado |
|---|---|
| Signo do Norte | Qualidade a desenvolver |
| Casa do Norte | Área da vida onde crescer |
| Signo do Sul | Qualidade herdada / zona de conforto |
| Casa do Sul | Área onde repete padrões |
| Aspectos ao Norte | Lições ativas |
| Aspectos ao Sul | Padrões a soltar |
| Regente do Norte | Como a jornada se manifesta |
| Regente do Sul | O que precisa ser abandonado |
