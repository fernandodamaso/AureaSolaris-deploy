# Mansões Lunares

As 28 Mansões Lunares são divisões de ~12,8° ao longo da eclíptica, usadas desde a astrologia árabe tradicional para leitura de timing, caráter e eventos.

> **Caderno:** cada mansão terá sua ficha própria com essência, atlas simbólico e leitura operativa.
