# 06 Aspectos

As relações angulares entre os pontos do mapa — e as configurações que formam.

> [!NOTE] **Entradas YAML instanciadas** (todas com `camada_energetica:`, `arquetipos_simbolicos:`, `aplicativo_separativo:` específico, e `exemplo_pratico:`):
> - **Ptolomaicos:** `Conjuncao`, `Oposicao`, `Quadratura`, `Trigono`, `Sextil`, `Quincuncio` (este último com leitura cármica).
> - **Menores:** `Semissextil`, `Sesquiquadrato`, `Quintil`, `Decil` (sincronia/divina), `Septil` (destino/mistério), `Paralelo` (declinação).
> - **Padrões/Configurações:** `Yod` (Mão de Deus), `Pipa`, `Grande_Trigono`, `Grande_Cruz`, `Estrela_dos_Magos`, `Estrela_de_Davi`.
> Template em `00_Motor_de_Conhecimento/template_aspecto.yaml`.

## Tópicos
- Ptolomaicos e menores
- Orbes (Aplicativo, Separativo)
- Configurações (Stellium, Yod, Pipa, Grande Trígono, Grande Cruz, Estrela dos Magos, Estrela de Davi)
- Antiscia e Contra-antiscion
- Midpoints / Pontos Médios

## Camada Energética (o coração)
Cada aspecto é a *qualidade da correnteza* entre dois pontos. Ler o aspecto é ler como duas frequências se tocam. (Ver `00_Filosofia`, seção IV.)

> 💎 **Consensos simbólicos** que usei: Yod = Mão de Deus / chamado; Decil = sincronia ou intervenção divina; Quincúncio = ajuste ou nó cármico. São consensos de leitura, não verdades fixas — marcar escola ao citar.
