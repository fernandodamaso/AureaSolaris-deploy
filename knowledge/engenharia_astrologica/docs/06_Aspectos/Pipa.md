# Balde / Bucket e Pipa / Kite

Esta página antiga chamava de “Pipa / Bucket” uma única figura. A equivalência é incorreta e foi retirada para evitar que o material de estudo e o motor tratem as duas técnicas como sinônimas.

- **Balde / Bucket**: padrão de distribuição planetária com um planeta-punho; ver [Pipa.yaml](Pipa.yaml), cujo `id` editorial agora é `balde_bucket`.
- **Pipa / Kite**: geometria de aspectos: grande trígono, uma oposição e dois sextis; ver [Pipa_Kite.yaml](Pipa_Kite.yaml).

Ambas são formulações modernas. Não devem ser atribuídas a Ptolomeu nem usadas como substitutas de dignidade, casas, aspectos componentes e contexto.
