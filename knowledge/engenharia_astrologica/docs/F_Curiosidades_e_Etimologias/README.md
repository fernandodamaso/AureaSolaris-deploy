## Etimologias

- [Considerar = cum + sidera](etimologias.yaml)
- Desastre = *dis + astrum* = mau astro
- Influência = *influere* = fluir para dentro (dos astros)
- Lunático = *luna* = afetado pela Lua
- Mercúrio = *Mercator* = comerciante, mediador
- Saturno = *Satur* = saciado, completo → tempo como consumidor
- Júpiter = *Iuppiter* = pai Júpiter → expansão, lei, proteção
- Marte = *Mars* = guerra/defesa → força que corta
- Vênus = *Venus/Venustus* = bela, desejável → valores e prazer
- Astrologia = *astron + logia* = estudo/razão dos astros
