# 05 Casas

Onde a energia se manifesta.

> [!NOTE] **Entradas YAML instanciadas** (com bloco `camada_energetica:` e `foco_especial:` infantil/familiar): `Casa_1.yaml` a `Casa_12.yaml`. Template em `00_Motor_de_Conhecimento/template_casa.yaml`.

## Tópicos
- Sistemas de casas (Placidus, Inteiro, Koch, etc.)
- Significado das 12 casas
- Classificações (Angulares, Sucedentes, Cadentes)
- Ângulos do mapa (Ascendente, MC, Eixos)

## Camada Energética (o coração)
Cada casa é uma *área do campo* onde a mente tende a focar. Ler a casa é ler "onde a correnteza se forma". (Ver `00_Filosofia`, seção IV.)
