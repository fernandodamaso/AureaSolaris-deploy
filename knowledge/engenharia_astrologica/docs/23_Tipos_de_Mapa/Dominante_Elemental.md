## 📌 Essência

- Fogo (vontade/impulso)
- Terra (corpo/realidade)
- Ar (mente/relação)
- Água (emoção/intuição)

## ⚡ Camada Energética

**Campo mental:** A mente tende a operar pelo elemento dominante. Fogo=age, Terra=foca, Ar=relaciona, Água=sente.

**Permeação emocional:** Falta de elemento = campo emocional desafinado naquela frequência.

**Manifestação externa:** Eventos prováveis seguem a cor do elemento forte; o fraco traz 'azar' percebido onde há só desequilíbrio.

## 📚 Origens e Divergências

- **Tradicional:** Ptolomeu (sect, diurno/noturno) + tradição árabe (oriental/ocidental).
- **Moderna:** Astrologia psicológica (mapa como 'retrato da alma').
