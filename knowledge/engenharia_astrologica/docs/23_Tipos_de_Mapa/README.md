# 23 Tipos de Mapa

Como classificar o temperamento e a origem do mapa.

> [!NOTE]
> Há **3 camadas distintas** aqui — não confunda:
> 1. **Qualidades do Mapa** — o "temperamento" do mapa natal (diurno/noturno, oriental/ocidental, dominante elemental…).
> 2. **Mapas Derivados** — mapas calculados a partir do natal (retorno solar, progressão, revolução…).
> 3. **Técnica de Sobreposição** — como comparar dois mapas (sinastria).

## Entradas YAML instanciadas
- **Qualidades:** `Sect.yaml` (diurno/noturno), `Oriental_Ocidental.yaml`, `Dominante_Elemental.yaml`
- **Padrões de Aspecto (qualidade estrutural):** `Padroes_Aspecto.yaml`
- **Mapas Derivados:** `Retorno_Solar.yaml`, `Progressao.yaml`, `Composite.yaml`
- **Relacionamentos:** `Mapa_Relacionamento.yaml` (navegação entre sinastria, composite e Davison)

## Camada Energética (o coração)
O "tipo" do mapa é a cor de fundo sobre a qual tudo o mais se lê. (Ver `00_Filosofia`, seção IV.)
