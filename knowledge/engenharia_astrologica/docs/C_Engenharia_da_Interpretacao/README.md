# ⚙️ C — Engenharia da Interpretação

Como tirar os símbolos do tabuleiro e montar a história de uma vida.

> A interpretação não é uma lista de significados colados. É uma argumentação, como um julgamento judicial: pesos, evidências, contexto, contradições e síntese.

---

## As 4 Tradições de Interpretação

É fundamental não misturar sem avisar:

| Tradição | Objetivo | Foco |
|---|---|---|
| 🏛️ **Tradicional** | Julgamento, destino, eventos | Técnica, promessa natal, timing |
| 🔮 **Hermética/Mágica** | Correspondências, transformação | Símbolo, analogia, operação |
| 🧠 **Psicológica** | Consciência, integração | Arquétipo, inconsciente, padrão |
| ✨ **Evolutiva** | Propósito da alma, karma | Nodos, Plutão, encarnação |
