## O que é este projeto

A **Engenharia Astrológica** é uma técnica própria de interpretação astrológica estruturada em camadas:

1. **Astros → Pensamento → Emoção → Evento PROVÁVEL** (a corrente energética)
2. **Arquétipos e personagens simbólicos** (não só dados)
3. **Alerta, não destino** — "astrologia inclina, não determina"

## Como usar este site

- Navegue pelo menu lateral
- Cada YAML tem `camada_energetica:` (o coração) + `origens_e_divergencias:` (a fonte)
- Use a busca (Ctrl+K) para encontrar conceitos
- Glossário bilíngue em `99_Referencia/`
