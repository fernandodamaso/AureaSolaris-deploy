# 22 Lotes / Partes Arábicas — Profundidade Total

Os Lotes são pontos matemáticos que representam a interseção de três princípios cósmicos. São o "resultado" de uma equação entre dois planetas e o Ascendente.

> [!NOTE] **Entradas YAML instanciadas** (com `camada_energetica:` e fórmulas diurna/noturna): `Fortuna.yaml`, `Espirito.yaml`, `Eros.yaml`, `Necessidade.yaml`, `Coragem.yaml`, `Vitoria.yaml`, `Base.yaml`, `Casamento.yaml`, `Filhos.yaml`, `Pais.yaml`, `Morte.yaml`. (12 lotes principais cobertos.)

## Fundamento
- Lotes helenísticos vs. Partes Arábicas medievais
- Cálculo: `Lote = Ascendente + Planeta A − Planeta B`
- Fórmulas **diurnas** (mapa nascido de dia)
- Fórmulas **noturnas** (mapa nascido de noite) — invertidas para os maléficos

## Como Usar
- Lote interpretado como ponto sensível do mapa
- Regente do Lote como indicador chave
- Ativação dos Lotes por trânsito e profeção
- Lotes diurnos vs. noturnos (a inversão muda tudo!)
