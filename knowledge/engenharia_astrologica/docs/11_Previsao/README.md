# 11 Técnicas Preditivas

O desdobramento da promessa natal no tempo.
## Tópicos

- [Timing](Timing.yaml) — cruzamento de técnicas para determinar quando
- [Lunações](Lunacoes.yaml) — fases da Lua como marcos emocionais
- [Eclipses](Eclipses.yaml) — gatilhos previsíveis e série Saros
- [Direções Primárias](Direcoes_Primarias.yaml) — método tradicional por grau/ano
- [Progressões](Progressoes.yaml) — evolução interna por dias/anos
- [Revolução Solar](Revolucao_Solar.yaml) — mapa do retorno solar anual
- [Firdárias](Firdaria.yaml) — períodos regentes persas por planeta
- [Fluxogramas](Fluxogramas.yaml) — ordem visual de leitura do mapa
- [Julgamento](Julgamento.yaml) — síntese e confirmação antes de afirmar

---

> **Camada energética aplicada ao timing:** nenhuma data é destino. O timing é janela de probabilidade; a resposta é livre-arbítrio.
