## Fundamento
- **Base canônica:** Hipócrates, Dioscórides, Culpeper, Agrippa (Doutrina das Assinaturas).
- **Overlay moderno:** Astrologia psicológica (Liz Greene) — corpo como linguagem simbólica.
- **Regra editorial:** este bloco preserva correspondências, diagnósticos, prognósticos e prescrições quando pertencem à fonte histórica estudada; a camada ética regula apenas a disseminação contemporânea a terceiros.
