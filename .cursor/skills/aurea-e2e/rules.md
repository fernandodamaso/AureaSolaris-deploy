# Hard rules

1. Never seed, reset, delete, or open `%LOCALAPPDATA%\Aurea Solaris\data`.
2. Refuse if `/health` is not `test_user: true`.
3. Do not put API keys, tokens, or personal notes in reports.
4. Default Hermes mode is mocked (Playwright routes). Live provider only on explicit request.
5. Saúde is study/preview — never diagnose or prescribe.
6. Missing UI for a playbook step = fail that id, do not silent-skip.
7. Prefer Portuguese accessible names for clicks.
